# Art Generation Prompts — copy-paste kit

Every fenced block below is a **complete, self-contained prompt** — copy one whole block into ChatGPT per request. The style description is repeated inside each block so nothing else is needed.

Tips:
- One block per chat message; if a grid comes back crowded, ask it to "redo as two sheets" with half the list.
- After the first sheet you like, you can add: "match the exact style of the attached previous sheet" and attach it.
- For items you'll cut out in-engine, add: "plain solid pale background, no drop shadows outside the outlines".
